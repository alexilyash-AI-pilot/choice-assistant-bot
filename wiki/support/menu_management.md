# Menu Management

Common issues with menu visibility, dish display, and additions.

---

## Menu shows as closed — why?

**Check in admin panel → Menu section:**
1. Confirm the menu is **enabled/active** (toggle is on)
2. Check the **schedule settings** — opening hours might be restricting access
3. Verify the menu is assigned to the correct location/branch

If enabled and schedule is correct but still closed — contact Choice support.

---

## Dishes are blank or not showing at all

Check each of the following in order:

**1. Category enabled?**
- Open menu settings → confirm category is active (not hidden)
- Check if time restrictions are set (availability hours)
- Confirm category is assigned to the correct menu

**2. POS integration active?**
- If you use a POS system, each dish must have a POS ID assigned
- Without a POS ID the product won't appear
- To find POS IDs: Admin panel → Features → Integrations with POS Systems → click "Menu" button → downloads Excel file with all POS IDs
- Add POS ID to dish by opening the dish in the menu editor and pasting into the "POS ID" field
- For tables: open the table in the "Areas" section and paste the POS ID

**3. Translation missing?**
- Red dots next to a category or dish = missing translation for the active language
- Fill in the missing translations to fix display

**4. Dish not showing on marketplace specifically?**
- Check if the dish photo meets marketplace requirements (contact marketplace support for exact specs)
- Confirm dish is enabled and set as available for that marketplace in the Choice panel
- Re-sync after making changes (Menu → Synchronization → select items → Save)

## How to add additions (modifiers) to a dish

1. Open admin panel → Menu editor
2. Go to the relevant menu section
3. Locate the addition group in **"All Additions"** — if it's not in "Used for This Section", click **"Pin"** to move it there
4. Once pinned, open the dish you want to modify → select the addition group from **"Sets of Additions"**

---

## How to open or close the menu during busy days

Manage per order type (delivery / takeaway / dine-in) from the admin panel menu section. Each type can be toggled independently.

---

## New items added in Choice not appearing on marketplace

1. Admin panel → Menu → **Synchronization**
2. Find "ITEMS" section
3. Select the item or category you want to push to the marketplace
4. Click **Save**

Sync can be done manually (click "Sync Menu" button) or automatically via live updates. If the "Sync Menu" button is grey, auto-sync is active — toggle the switch to enable manual sync.

---

## How does menu translation work?

Menu translations are managed in the menu editor. Each dish, category, and option can have a name and description set per language. Red dot = translation missing for that language. The system supports 99 languages via automatic translation — manual review recommended for accuracy.
