# Choice Products — Index

Choice offers a fully integrated suite of products. All products are managed from a single admin panel and the **Choice Business** mobile app.

**Built for chains:** Choice supports full multi-location management — menu, pricing, promotions, analytics, and loyalty can all be managed centrally across all locations from one admin panel.

## Key Integrations

- **Delivery Marketplaces:** Wolt, Bolt Food, Foodora, Glovo, Uber Eats, Just Eat / Pyszne.pl, Bistro.sk, LOKO
- **On-demand Couriers:** Wolt Drive, Stuart, Glovo On-Demand, Foodora Go, Uber Direct, Uklon (UA)
- **POS Systems:** Poster, Dotykačka, Syrve (iiko), Servio, R-Keeper, Profit, Storyous, Restis, Compucash, ID POS, POS ID sync
- **Payments:** All major cards (Visa, Mastercard, Amex, Maestro), Apple Pay, Google Pay — processed via Adyen, Fondy, LiqPay
- **Marketing:** Google Analytics, Facebook Pixel, Google Tag Manager
- **Reviews:** Google Maps, TripAdvisor
